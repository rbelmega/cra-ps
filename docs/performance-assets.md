# Performance assets

Keep the original TTF fonts and `public/assets/img/me2.jpg` as the sources. The app
serves derived WOFF2 fonts and responsive WebP portraits to reduce initial downloads.

## Fonts

The homepage preloads small Basic Latin subsets of the medium and text fonts,
covering its English content and common punctuation. Full WOFF2 fonts remain in the
font-family stacks for accented Latin, Cyrillic, Greek, and other supported characters.
The thin font loads only on pages that use it. Latin subsets preserve glyph outlines,
advance widths and OpenType layout features. The web subsets omit TrueType hinting
instructions to reduce their payload; the original full fonts retain them.

To regenerate the assets in an activated Python environment:

```sh
python -m pip install 'fonttools[woff]==4.60.2' 'brotli==1.2.0'
for weight in thin medium text; do
  python -m fontTools.ttLib.woff2 compress \
    "public/assets/fonts/myriad-set-pro_${weight}.ttf" \
    -o "public/assets/fonts/myriad-set-pro_${weight}.woff2"
done
for weight in medium text; do
  pyftsubset "public/assets/fonts/myriad-set-pro_${weight}.ttf" \
    --output-file="public/assets/fonts/myriad-set-pro_${weight}-latin.woff2" \
    --flavor=woff2 --layout-features='*' --name-IDs='*' --name-languages='*' \
    --notdef-outline --no-hinting \
    --unicodes='U+0000-007F,U+00A0,U+00A9,U+00B7,U+2000-206F,U+20AC,U+2122,U+2212,U+FEFF,U+FFFD'
done
```

Keep the subset ranges in sync with `unicode-range` declarations in `Document.tsx`
and `App.tsx`. Neither original font contains ↗, so the certification arrow uses a
system font directly rather than triggering a full font download before falling back.

## Portrait

The homepage uses native responsive images with WebP variants generated by the
project's existing Sharp dependency. Regenerate them after replacing the portrait:

```sh
node <<'NODE'
const sharp = require('sharp');
(async () => {
  for (const width of [128, 320, 640, 1024]) {
    await sharp('public/assets/img/me2.jpg').rotate().resize(width)
      .webp({ quality: 75 }).toFile(`public/assets/img/me2-${width}.webp`);
  }
})();
NODE
```

`npm test` checks the homepage's critical font and JavaScript payload budgets.
Run `npm run lighthouse` after asset changes to compare actual browser measurements.

The modern favicon is the existing ICO's 64×64 PNG frame, extracted without changing
its pixels. The original multi-resolution ICO remains available for older clients.
